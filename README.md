# 문서 변경 비교기 (무료 문서 질문 기능 포함)

이 연습용 웹 앱은 이전 문서와 수정 문서를 비교하고 추가·삭제된 줄을 표시합니다. TXT, DOCX, 텍스트가 선택되는 PDF, HWPX, 일부 HWP 파일을 지원합니다. 문서에서 질문과 관련된 문장을 찾아 보여주는 간단한 문서 질문 기능도 포함합니다.

> 교육용 예제입니다. 공식 GMP/품질 검토나 승인을 대신하지 않습니다. 공개 링크에 실제 회사 문서, 개인정보, 비밀 문서를 올리지 마세요.

## 인터넷에서 누구나 쓰는 앱 만들기

### 1. GitHub에 파일 올리기

GitHub 저장소는 Public이어도 됩니다. 저장소에는 `app.py`, `requirements.txt`, `README.md`만 올리세요. API 키, `.venv` 폴더, 실제 문서는 올리지 마세요.

### 2. Streamlit Community Cloud에서 배포하기

1. https://share.streamlit.io 에서 GitHub로 로그인합니다.
2. **Create app**을 누르고 GitHub 저장소를 선택합니다.
3. 브랜치는 `main`, 앱 파일은 `app.py`로 지정하고 **Deploy**를 누릅니다.
4. 배포가 끝나면 만들어진 `.streamlit.app` 주소를 다른 사람에게 전달합니다.

### 3. 앱 사용하기

이 버전은 문서 질문 기능에 외부 AI API 키가 필요하지 않습니다. 방문자 모두가 같은 앱을 열어 문서를 비교하고 질문할 수 있습니다.

## 내 컴퓨터에서 실행하기

1. Python 3.11 이상을 설치합니다.
2. 이 폴더에서 PowerShell을 열고 다음을 한 줄씩 실행합니다.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

3. 브라우저에서 표시되는 `http://localhost:8501` 주소를 엽니다. 앱을 쓰는 동안 PowerShell 창을 닫지 마세요.

외부 서비스 API를 사용하지 않으므로 API 키나 결제 설정이 필요하지 않습니다.

## 개인정보와 무료 등급 안내

파일 텍스트 추출, 비교, 질문과 관련된 문장 검색은 앱 서버에서 처리합니다. 질문 기능은 Python의 문자 비교와 검색 규칙을 사용하며 문서 내용을 외부 AI 서비스로 보내지 않습니다. 공개 링크이므로 민감 문서 대신 공개 가능한 가상 문서를 사용하세요. 호스팅 서비스 자체에는 처리 자원과 이용 조건이 적용될 수 있습니다.

## 비교의 한계

- 비교는 글자를 추출한 다음 줄 단위로 수행합니다.
- 질문 기능은 관련 문장을 찾아 보여주는 간단한 검색 방식입니다. 생성형 AI처럼 문장을 자유롭게 이해하거나 새로운 답을 만들어내지는 않으며, 표현이 다르면 관련 내용을 찾지 못할 수 있습니다.
- 스캔 이미지 PDF는 글자를 추출할 수 없으며 OCR도 포함되어 있지 않습니다.
- HWP 표·글상자·수식은 일부 누락되거나 순서가 달라질 수 있습니다. 가능하면 HWPX나 DOCX를 사용하세요.
- AI 답변은 틀릴 수 있으며 공식 검토나 승인을 대신하지 않습니다.
